# 03 · 分阶段任务清单

[← 返回总览](README.md)

> **排期假设**：一个人、每周投入约 20 小时，日常用 AI 编程助手（Claude Code / Codex）提速。
> 全职投入的话，整体可以压缩到 10–12 周。
>
> **优先级**：P0 = 不做不行；P1 = 这一阶段应该做完；P2 = 有余力再做 / 探索性质。
> **任务 ID** 可以直接拿来当 GitHub Issue 标题前缀，验收标准就是 Issue 的完成定义。
> ✅ 表示已完成，进度明细见 [总览 · 进度记录](README.md#进度记录)。

## 测试策略

## 用 AI 编程助手提速的建议

从 `PROGRESS.md` 看得出来，你已经大量用 AI 助手写代码了。升级期间建议这样用：

1. **每个任务一个 Issue**：把上面表格里的"任务 + 验收标准"原样贴进 Issue，AI 助手拿到的就是一份清楚的需求。
2. **每个包一份 `CLAUDE.md` / `AGENTS.md`**：写清这个包的职责、边界和测试命令，避免助手跨包乱改。
3. **CI 是最后一道关**：不管是谁写的代码，CI 不绿就不合并。
4. **风控包人工逐行审**：这一块不要完全交给 AI。
