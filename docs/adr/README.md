## 怎么写一篇新的 ADR

复制下面的模板，编号顺延，文件名用英文短语：

```markdown
# ADR-000N：标题

- 状态：提议中 / 已采纳 / 已废弃（被 ADR-000M 取代）
- 日期：YYYY-MM-DD

## 背景
为什么现在要做这个决定，约束条件是什么。

## 选项
1. ……
2. ……

## 决定
选了哪个，一两句话说清楚理由。

## 后果
好处、代价、以后要注意什么。
```

拍板的方式很简单：把"状态"改成"已采纳"，写上日期，在 PR 里说一句就行。
